Política de Privacidade

Aplicativo: Automacao_Marcenaria

Última atualização: 13 de outubro de 2026

1. Introdução

Esta Política de Privacidade explica como o responsável pelo aplicativo Automacao_Marcenaria poderá coletar, utilizar, armazenar e proteger dados pessoais processados por suas funcionalidades e integrações.

O aplicativo é um projeto independente de uso pessoal. Os dados serão tratados conforme a legislação aplicável, incluindo a Lei Geral de Proteção de Dados Pessoais (Lei nº 13.709/2018), quando aplicável.

2. Dados que podem ser processados

De acordo com as funcionalidades ativadas e as permissões concedidas, o aplicativo poderá processar informações fornecidas pelos usuários ou disponibilizadas por plataformas integradas, tais como:

  • nome ou identificador do usuário;
  • número de telefone e informações de contato, quando disponibilizados;
  • mensagens, solicitações e conteúdos enviados voluntariamente;
  • informações técnicas e registros necessários ao funcionamento e à segurança do aplicativo.

Somente devem ser tratados os dados necessários para as finalidades descritas nesta Política e para as funcionalidades efetivamente utilizadas.

3. Como os dados são utilizados

Os dados poderão ser utilizados para executar as funcionalidades do aplicativo, receber e responder a solicitações, realizar automações, integrar serviços, solucionar falhas técnicas e, quando aplicável, processar mensagens com recursos de inteligência artificial.

Os dados não devem ser utilizados para finalidades incompatíveis com as informadas ao usuário, salvo quando houver fundamento legal adequado.

4. Compartilhamento de dados

Quando necessário para fornecer as funcionalidades do aplicativo, os dados poderão ser transmitidos a plataformas integradas, provedores de hospedagem ou infraestrutura e serviços de inteligência artificial. O compartilhamento deve ser limitado ao necessário para a operação do serviço e observar as obrigações de proteção de dados aplicáveis.

O responsável pelo aplicativo não comercializa dados pessoais.

5. Armazenamento e segurança

Serão adotadas medidas técnicas e organizacionais razoáveis para proteger os dados contra acesso não autorizado, perda, alteração ou divulgação indevida. Os dados serão mantidos pelo período necessário às finalidades do aplicativo ou conforme exigido pela legislação aplicável.

Nenhum sistema pode garantir segurança absoluta, mas serão adotadas medidas razoáveis para reduzir os riscos relacionados ao tratamento de dados pessoais.

6. Serviços de terceiros

O aplicativo poderá utilizar APIs e serviços externos. O tratamento realizado diretamente por esses fornecedores também poderá estar sujeito às respectivas políticas e condições. O acesso às informações das plataformas integradas dependerá das permissões concedidas e dos requisitos aplicáveis.

7. Direitos dos titulares

Os titulares poderão solicitar, quando aplicável, confirmação do tratamento, acesso, correção, eliminação e outras providências previstas na legislação. As solicitações serão avaliadas conforme as circunstâncias e as obrigações legais de conservação.

8. Solicitação de exclusão de dados

Para solicitar a exclusão de dados pessoais tratados pelo aplicativo, envie um e-mail para nicanor.floresm@gmail.com com o assunto “Solicitação de exclusão de dados – Automacao_Marcenaria”. Inclua informações suficientes para identificar a solicitação, evitando enviar dados pessoais desnecessários.

Após a verificação necessária, serão adotadas as medidas cabíveis para excluir os dados mantidos pelo aplicativo, ressalvadas as hipóteses legais de conservação. A exclusão de dados mantidos diretamente por plataformas externas poderá precisar ser solicitada ao respectivo fornecedor.

9. Alterações nesta Política

Esta Política poderá ser atualizada quando houver mudanças relevantes no aplicativo, nas integrações ou nas práticas de tratamento de dados. A versão vigente será publicada nesta mesma página, com a respectiva data de atualização.
